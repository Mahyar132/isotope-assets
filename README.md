# Isotope Assets

A dumb CDN for assets used by [Isotope](https://github.com/Mahyar132/Mahyar132.github.io)

## About

This repository contains image assets and other visual resources used across the Isotope website.

## Contents

### Emotes

The `emote/` directory contains cat emoji artwork from [Noto Emoji](https://github.com/googlefonts/noto-emoji).

The original artwork is provided by Google **(Uncomfortably!)** and its respective contributors.
